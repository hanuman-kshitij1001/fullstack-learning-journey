## 🛠️ Projects Built

Hands-on mini-projects built along the way to solidify concepts:

### 1️⃣ CSS-Only Sidebar Drawer Menu
📂 `09_CSS_First_Project_5_1`
A responsive sidebar navigation drawer using Google Fonts, Font Awesome icons, and the **CSS checkbox hack** (`:checked` pseudo-class + sibling combinators) — full show/hide functionality with **zero JavaScript**.

### 2️⃣ Interactive DOM-Based To-Do List
📂 `22_JavaScript_part_11_(Mini-Projects)_11`
A task management app built with vanilla JS DOM APIs. Supports adding/deleting tasks dynamically using **event delegation** on a parent container.

### 3️⃣ Simon Says — Sequence Memory Game
📂 `22_JavaScript_part_11_(Mini-Projects)_11`
A classic memory game with level progression, random color sequences, flash animations via `setTimeout`, and error/reset handling.

### 4️⃣ Dog API Random Image Generator
📂 `26_JavScript_Part_15`
An **Axios** + `async`/`await` powered app that fetches random dog images from the public `dog.ceo` API and updates the DOM on click.

### 5️⃣ RESTful Posts CRUD Server
📂 `34_Backend_REST_Part_4`
A full Express + EJS backend app implementing complete RESTful CRUD — Index, New, Create, Show, Edit, Update, Destroy — with `method-override` and UUID-based IDs.

### 6️⃣ Random RGB Color Generator
📂 `21_JavaScript_Part_10`
Generates random `rgb(r, g, b)` values on click and dynamically updates background color + displayed color code.

## ⚙️ Backend Implementation Details

### 🟢 Node.js Core Fundamentals
- `process.argv` for shell input arguments
- CommonJS module system (`module.exports` / `require()`)
- npm project setup & local/global dependency management

### 🚂 Express.js Server Framework
- Routing with `app.get()` and HTTP method handlers
- `req.params` and `req.query` for dynamic routes
- EJS templating — views, interpolation, conditionals, includes
- Static asset serving via `express.static()`

### 🔗 RESTful API Design
| Action | Route | Method |
| :--- | :--- | :--- |
| Index | `/posts` | `GET` |
| New | `/posts/new` | `GET` |
| Create | `/posts` | `POST` |
| Show | `/posts/:id` | `GET` |
| Edit | `/posts/:id/edit` | `GET` |
| Update | `/posts/:id` | `PATCH` |
| Destroy | `/posts/:id` | `DELETE` |

- Middleware parsing via `express.urlencoded()` and `express.json()`
- `method-override` for PATCH/DELETE support in HTML forms
- `res.redirect()` for post-action navigation

### 🗄️ Relational SQL Databases
- Schema design with `CREATE DATABASE` / `CREATE TABLE`
- Constraints: `NOT NULL`, `UNIQUE`, `DEFAULT`, `CHECK`
- Primary Keys & Foreign Keys for relational modeling
- CRUD queries: `INSERT`, `SELECT`, `WHERE`, `ORDER BY`, `UPDATE`, `DELETE`
